# 苹果收集者 (Apple please)

一款 3D 第三人称收集类小游戏。玩家操控角色在平台上收集随机掉落的苹果，
通过 3 天（每天 60 秒）的收集赚取金币，购买升级，最终跳上高处平台获取大苹果获胜。

## 游戏玩法

1. 开始界面 → 进入游戏
2. 每天 60 秒，共 3 天，收集从平台上方掉落的苹果
3. 苹果分三色：红（3分）、黄（2分）、绿（1分）
4. 每日结束后，当局分数 ×5 结算为金币
5. 在商店购买三项升级：
   - 红苹果出现概率上升
   - 角色移动速度提高
   - 平台扩大（价格最高）
6. 攒够钱扩大平台后，可跳跃至远处平台获取大苹果（有箭头标注）
7. 拿到大苹果 → 胜利结局；掉入悬崖 / 3天内未拿到大苹果 → 失败结局

## 操作方式

- **移动**：WASD / 方向键
- **跳跃**：空格
- **冲刺**：Shift
- **冲刺+跳跃**：触发星星粒子效果

## 核心系统与技术实现

### 1. 游戏流程状态机
- 使用状态机管理：开始、游戏中、死亡、商店、结局
- 各状态通过事件切换，便于扩展新功能

### 2. 苹果生成系统
- 三个独立苹果模型（红 / 黄 / 绿），按权重随机选择
- 在平台上方限定正方形区域内随机位置生成
- 商店升级动态调整红苹果权重，逻辑与配置分离
- 苹果落地后正弦浮动 + 自转，几秒后消失

### 3. 经济与升级系统
- 每日分数 ×5 结算金币
- 三项升级独立配置（数据驱动），修改数值无需改动代码

### 4. 角色控制与物理交互

- **第三人称移动**：基于 Rigidbody.AddForce 的力驱动移动，支持前后左右、跳跃、冲刺
- **加速/减速**：通过施加力与阻力参数控制，从静止加速到匀速，松开后减速至停止，手感自然
- **跳跃惯性**：跳跃保留水平速度，空中可微调方向，落地后惯性衰减
- **冲刺跳跃**：冲刺+跳跃组合触发星星粒子效果（Particle System）
- **碰撞检测**：触发器判定苹果与篮子、角色与悬崖
- **物理交互**：苹果落入篮子判定、苹果落地后正弦浮动+自转、超时消失

### 5. UI 系统
- 开始界面、游戏中 HUD、死亡界面、商店界面、结局界面
- 全流程 UI 独立设计
